# shafi-/homebrew

Homebrew tap for all shafi- tools.

## Installation

```bash
brew tap shafi-/homebrew
brew install portfolio
```

## Available Tools

- **portfolio** - Local-first project inventory and knowledge platform

## Usage

After installation, you can use Portfolio from your command line:

```bash
portfolio --help
portfolio --version
```
